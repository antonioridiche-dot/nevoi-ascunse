# Surse de migrare aprobate

## Weightloss

`weight-los-manifest` și `romanian-weightloss-funnel` reprezintă **o singură ofertă publică**. Ruta unică este `/oferte/weightloss`, iar brandul unic este `weightloss`.

Repository-ul `romanian-weightloss-funnel` este sursa principală a flow-ului complet — checkout, upsell-uri, pagini post-cumpărare, afiliere și administrare. Repository-ul `weight-los-manifest` este o sursă secundară aprobată doar pentru componentele și resursele care trebuie păstrate în aceeași ofertă. Nu se creează o a doua rută, o a doua pagină de vânzare sau un al doilea checkout pentru Weightloss.

## Relații

`dic-ionarul-rela-iilor` este sursa unică pentru ruta `/oferte/relatii`. Repository-ul `dictionarulrelatiilor` este arhivă tehnică și nu devine brand public separat.

## Excluderi

Repository-urile `tevreauinapoi`, `groworpay`, `grow-or-pay` și `parinte-de-succes` nu fac parte din platforma unificată.
